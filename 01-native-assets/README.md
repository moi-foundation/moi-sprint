## Key Concepts

### Native Assets
MOI supports tokens at the protocol level - no smart contracts needed! This means faster, cheaper, and simpler token operations.

### Participant-Centric Architecture
Unlike traditional blockchains, MOI stores asset ownership in the participant's account, not in a contract. This eliminates state bloat and enables parallel execution.

### TDU (Transaction Data Unit)
Efficiently query an account's complete asset portfolio in a single call.
