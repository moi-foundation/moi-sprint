# MOI Sprint

> **MOI Sprint is the starting point for developers to learn how to use our tech stack to build on a contextual compute network.**

A structured learning path to master building on MOI. Each chapter contains tutorials, examples, and hands-on projects.

## 🚀 Getting Started

MOI Sprint is designed as a progressive learning journey. Start with Chapter 1 and work your way through each chapter to build your understanding of MOI's architecture and capabilities.

## 📚 Chapters

### Chapter 1: Native Assets
Build a simple fixed rate exchange on MOI.

👉 **[Start Chapter 1 →](./01-native-assets/README.md)**

## 🛠️ Prerequisites

- Node.js v16+
- Basic JavaScript knowledge
- [IOMe Wallet](https://voyage.moi.technology) - Create and fund your wallet
- [Coco CLI](https://cocolang.dev) - For compiling contracts
